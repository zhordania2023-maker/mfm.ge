# MFM საქართველო — ვებგვერდი

დედა-ნაყოფის მედიცინის საზოგადოების (MFM Georgia) საიტი: კლინიკური გაიდლაინები,
უწყვეტი განათლება, ღონისძიებები, სპეციალისტების კატალოგი, წევრობა და პაციენტთა
რესურსები. სტრუქტურა და ფუნქციონალი აგებულია [smfm.org](https://www.smfm.org/)-ის
ლოგიკაზე, სრულად ქართულ ენაზე.

## ტექნოლოგიები

| | |
|---|---|
| ფრეიმვორკი | Next.js 16 (App Router, Turbopack) |
| ენები | ქართული + ინგლისური (`/ka/…`, `/en/…`) |
| ენა | TypeScript |
| სტილები | Tailwind CSS v4 (`@theme` + `@layer`) |
| შრიფტი | Noto Sans Georgian (`next/font/google`) |
| გამოსახულებები | Unsplash-ის ფოტოები (`src/content/images.ts`) + სარეზერვო SVG |

## გაშვება

```bash
npm install
```

```bash
npm run dev
```

გაიხსნება `http://localhost:3000`.

სხვა ბრძანებები:

```bash
npm run build
```

```bash
npm run lint
```

## ორენოვნება

- მისამართი: `/ka/…` და `/en/…`; `/` ავტომატურად გადამისამართდება (cookie → Accept-Language → ka).
- გადამრთველი ჰედერშია (`ქარ | ENG`); ინახავს არჩევანს cookie-ში და ტოვებს იმავე გვერდზე.
- ნათარგმნია **ყველაფერი**: ნავიგაცია, 12 სიახლე, 14 გაიდლაინი, 8 ღონისძიება,
  15 სპეციალისტი, კურსები, კლინიკური შემთხვევები, FAQ, ფორმები, API-ს პასუხები,
  თარიღების ფორმატი და SEO მეტამონაცემები (`hreflang` ჩათვლით).
- ახალი ენის დამატება: `src/i18n/config.ts` + `src/content/<ენა>/` + `src/i18n/ui.ts`.

## ფუნქციონალი

- **მეგა-მენიუ** — ხუთი განყოფილება, თითოეული ორი სვეტითა და აქცენტის ბანერით
  (დესკტოპი ≥1280px, სხვაგან — გვერდითი მენიუ აკორდეონებით).
- **საიტის ძიება** — `Ctrl/⌘+K` ან `/`; ინდექსი იგება სერვერზე (`/api/search`),
  ცალკე თითოეული ენისთვის, და მოიცავს გაიდლაინებს, სიახლეებს, ღონისძიებებს,
  კურსებს, კლინიკურ შემთხვევებს, სპეციალისტებსა და ხშირ კითხვებს.
- **ქართული მორფოლოგია ძიებაში** — მსუბუქი სტემინგი (`src/lib/utils.ts`),
  რომ „პრეეკლამფსია“ იპოვოს „პრეეკლამფსიის“ ფორმაც.
- **გაიდლაინების ბიბლიოთეკა** — თემა, ტიპი, წელი, დახარისხება, ტექსტური ძიება.
- **ღონისძიებები** — მომავალი/წარსული, ტიპის ფილტრი, `.ics` კალენდარში დამატება.
- **სპეციალისტის ძებნა** — ქალაქი, სუბსპეციალობა, ენა, ტელემედიცინა, მიმართვები.
- **კვირის კლინიკური შემთხვევა** — ინტერაქტიული კითხვა პასუხის განხილვით.
- **გაწევრიანების ფორმა** — სამნაბიჯიანი, ველების ვალიდაციით.
- **SEO** — თითო გვერდის მეტამონაცემები, `sitemap.xml`, `robots.txt`, ქართული `lang`.
- **ხელმისაწვდომობა** — skip-link, `aria-*`, კლავიატურით ნავიგაცია, focus-ring,
  `prefers-reduced-motion` მხარდაჭერა.

## კონტენტის რედაქტირება

ტექსტები და მონაცემები **კოდში არ არის გაბნეული** — ყველაფერი `src/content/`-შია.

- ახალი სიახლე → ჩანაწერი `news.ts`-ის მასივში (გვერდი ავტომატურად შეიქმნება).
- ახალი გაიდლაინი → `guidelines.ts`; ღონისძიება → `events.ts`.
- მენიუს ცვლილება → `nav.ts`.
- საკონტაქტო მონაცემები, სტატისტიკა → `site.ts`.

## გამოსახულებები

ყველა სურათი **ერთ ფაილშია** — [`src/content/images.ts`](src/content/images.ts).

ამჟამად გამოყენებულია Unsplash-ის უფასო ლიცენზიის ფოტოები (კომერციული
გამოყენება დაშვებულია, ატრიბუცია სავალდებულო არ არის) — ორსული ქალები,
ექიმები, ულტრაბგერითი კვლევა, დედა ახალშობილთან, კონგრესი, ლაბორატორია,
ტელემედიცინა. `next.config.ts`-ში ამისთვის დაშვებულია `images.unsplash.com`.

**საკუთარი ფოტოებით ჩანაცვლება:** ჩააგდეთ ფაილი `public/img/`-ში და
`images.ts`-ში შეცვალეთ მხოლოდ გზა:

```ts
hero: "/img/hero.jpg",
```

`public/img/*.svg`-ში ისევ დარჩენილია სარეზერვო ვექტორული ილუსტრაციები.

## ლოგო

ლოგო ერთ ადგილას დევს — `public/img/`:

| ფაილი | სად გამოიყენება |
|---|---|
| `logo.png` | ჰედერი, 404, ბრაუზერის ტაბი, ძებნის შედეგი, სოციალური პრევიუ |
| `logo-light.png` | ფუტერი (მუქ ფონზე) |

ორივე გამჭვირვალე ფონითაა (თეთრი ფონი მოცილებულია) და კიდეებში
მოჭრილი, რომ პატარა ზომაზეც მკაფიო იყოს.

**შესაცვლელად:** უბრალოდ ჩაანაცვლე ეს ფაილები — კოდში არაფერია
შესაცვლელი. [`src/lib/logo.ts`](src/lib/logo.ts) ავტომატურად პოულობს
`logo.svg | .png | .webp | .jpg`-ს და არყოფნის შემთხვევაში ჩაშენებულ
ვექტორულ ნიშანზე გადადის.

## API მარშრუტები

`/api/contact`, `/api/join`, `/api/newsletter` — ვალიდაციას ასრულებენ და
პასუხს მომხმარებლის ენაზე აბრუნებენ, მაგრამ **წერილს არ აგზავნიან**. პროდაქშენში ჩასართავია
ელფოსტის სერვისი (Resend, SendGrid, SMTP) ან CRM შესაბამის `route.ts`-ში.

ავტორიზაცია (`/login`) დემო რეჟიმშია — ბექენდი მიერთებული არ არის.

## დეპლოი

ნებისმიერ Node ჰოსტინგზე (`npm run build && npm start`).
